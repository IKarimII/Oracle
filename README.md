# Oracle

A ten-question quiz in which an orb appears to work out where you are from your answers.
It already knows: the location comes from an IP lookup made before the first question.

Built with Vite, React, TypeScript, Tailwind CSS and Leaflet. No backend.

```
npm install
npm run dev
```

Pressing Escape three times in a row clears what the orb remembers about you.
